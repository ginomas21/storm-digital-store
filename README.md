# Storm Digital Store

Website resmi Storm Digital Store — toko produk digital: akun & langganan premium, top up game, pulsa & paket data, voucher & e-money.

## Versi saat ini
- v1: website statis (HTML + CSS + JavaScript, satu file `index.html`)
- Hosting: Vercel, kode di GitHub
- Rencana: upgrade ke versi dinamis (Next.js) — katalog produk dari database, checkout QRIS otomatis.

## Cara update (versi statis)
Edit `index.html`, commit, push ke branch `main` — Vercel otomatis deploy ulang.
